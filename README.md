# 📂 Personal Portfolio Website

A clean, responsive, single-page portfolio website designed to showcase my software engineering skills, personal projects, and technical experience.

✨ **Live Demo:** [View my live portfolio website here]( https://github.com/Sakshi-hugar/my-portfolio.git)

## 🚀 Features

- **Responsive Design:** Optimized for seamless viewing across mobile, tablet, and desktop screens.
- **Project Showcases:** Interactive sections detailing my active development projects, including tech stacks and code links.
- **Contact Integration:** Quick-access links to my professional profiles, including email, LinkedIn, and GitHub.

## 🛠️ Built With

- **HTML5:** Semantic structure and content organization.
- **CSS3:** Custom layouts, responsive typography, and interface styling.
- **JavaScript (ES6+):** Interactive elements and dynamic user interface behaviors.

## 📁 File Structure

```text
├── index.html       # Main webpage structural markup
├── style.css        # Custom styles and layout rules
├── script.js        # UI interactivity script
└── README.md        # Project documentation
```
